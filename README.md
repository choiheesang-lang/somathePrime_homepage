# 소마 더 프라임 홈페이지

소마 더 프라임의 정식 홈페이지 프로토타입입니다. 마케팅팀 기획안(`소마더프라임 홈페이지 기획안_20261026.pptx`)을 바탕으로, 티징사이트(랜딩)의 디자인 시스템과 인트로 모션을 이어받아 만듭니다.

모양(V 꺾임 · 육각형) · 공통 컴포넌트 · 페이지 구성 규칙은 [docs/DESIGN.md](docs/DESIGN.md), 작업 기록과 토큰은 [docs/NOTES.md](docs/NOTES.md)에 있습니다.

## 보는 법

```bash
python3 -m http.server 8766
```

브라우저에서 http://localhost:8766 을 엽니다. 페이지가 `/css/...`처럼 사이트 루트 기준 주소를 쓰므로 파일을 더블클릭해서 열면 깨집니다.

- 인트로는 같은 탭에서 한 번만 나옵니다. 다시 보려면 `?intro=1`, 건너뛰려면 `?intro=0`.

## 진행 단계

| 단계 | 범위 | 상태 |
|---|---|---|
| 1 | 공통 틀(GNB · 전체 메뉴 · 퀵메뉴 · 등록 팝업 · 푸터) + 홈 | 진행 중 |
| 2 | 브랜드 소개 · 캠퍼스 안내 · 오시는 길 | 자리만 |
| 3 | 교육 프로그램 | 자리만 |
| — | 소식 · 수강료 납부 · 선생님 · 마이페이지 | 기존 서비스 연동 예정(자리 페이지) |

## 고치는 법

페이지 원본은 `src/pages/`, 모든 페이지에 들어가는 공통 조각(GNB · 푸터 · 팝업 · 로고 스프라이트 등)은 `src/partials/`에 있습니다. 고친 뒤 한 번 조립합니다.

```bash
python3 tools/build.py
```

루트의 `*.html`, `brand/*.html`은 조립 결과입니다 — 직접 고치지 말고 `src/`를 고치세요. 결과물도 커밋하므로 배포에는 빌드 단계가 없습니다.

| 폴더 | 내용 |
|---|---|
| `src/pages/` | 페이지 원본(맨 위 머리말에 제목 · 활성 메뉴 · CSS/JS) |
| `src/partials/` | 공통 조각 |
| `css/` | `tokens · base · sections · hero`는 랜딩에서 가져온 것, `site`는 공통, `home`은 홈 |
| `js/` | `hero`(인트로 — 랜딩 것 + 자동 재생), `lead`(등록 팝업), `site`(공통), `home` |
| `img/campus/` | 인테리어 시안(로고 적용, 10/26) 34장을 웹용으로 줄인 것 — 입구 · 강의실 · 라운지 |

## 서체
