# 디자인 원칙 — 소마 더 프라임 홈페이지

색 · 글꼴 · 간격 토큰과 작업 기록은 [NOTES.md](NOTES.md)에, 토큰 값은 `css/tokens.css`에 있습니다. 이 문서에는 화면 전체에 걸친 **시각 규칙**만 적습니다.

## 1. 아이덴티티 — 비주얼은 아래로 꺾인다

큰 비주얼은 아래쪽 가운데가 V자로 내려옵니다. 사이트를 알아보게 하는 첫 번째 표식입니다. 기준 시안은 피그마 18155-8483입니다.

```
┌───────────────────────────┐
│                           │
│          비주얼           │
│                           │
└──╲                     ╱──┘   ← 양 끝: 높이 − 꺾임 깊이
     ╲                 ╱
       ╲─────V───────╱          ← 가운데: 비주얼 맨 아래
```

- **쓰는 법**: 비주얼 상자에 `.is-folded` 클래스를 붙입니다(`css/site.css`). 잘린 양쪽에는 그 아래 바탕이 비칩니다.
- **깊이**: `--fold-depth: clamp(40px, 7vw, 136px)`입니다. 1920 폭에서 약 130px로 시안과 같고, 모바일에서는 40px입니다.
- **쓰는 곳**:
  - 메인 KV 사진(`.kv__slides`)
  - 서브 페이지 상단 비주얼: 브랜드 소개 · 캠퍼스 안내 · 오시는 길 · 교육 프로그램(2 · 3단계에서 붙임)
- **쓰지 않는 곳**: 카드, 썸네일, 팝업, 본문 속 작은 사진. 꺾임은 「페이지의 첫 큰 그림」에만 씁니다. 여러 번 쓰면 표식이 흐려집니다.
- **위에 얹는 것**: 글 패널처럼 비주얼 위에 뜨는 요소는 꺾인 부분(아래 `--fold-depth`)을 피해 둡니다. 모바일에서는 패널이 꺾임에 반쯤 걸쳐도 됩니다.

## 2. 메인 비주얼 — 미래탐구 구성 + 떠 있는 패널

미래탐구 브랜드 사이트의 비주얼(피그마 18155-8475)을 따릅니다.

| 요소 | 값 |
|---|---|
| 패널 | 왼쪽 화면 끝에서 뻗어 나온 카드, 사진 위에 뜸 · 바탕 #EEEFEC 92% + 블러 · 모서리 0 / 60 / 160 / 0 · `--shadow-lg` |
| 머리말 | 세방고딕 14 Bold · 「SOMA THE PRIME」 |
| 제목 | 세방고딕 46(모바일 34) · 행간 1.12 · 검정 78% |
| 본문 | Noto Sans KR 14 Medium · 행간 2 · 3줄 |
| 컨트롤 | `1 / 3` 14px · ‹ │ › 32px · 멈춤 32px 네모(테두리 10%, r8) · 아래 5초 진행 바 |

사진과 문구는 세 벌이 함께 넘어갑니다(5초). 1번 문구만 `h1`입니다.
