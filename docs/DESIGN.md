# 디자인 원칙 — 소마 더 프라임 홈페이지

색 · 글꼴 · 간격 토큰과 작업 기록은 [NOTES.md](NOTES.md)에, 토큰 값은 `css/tokens.css`에 있습니다. 이 문서에는 화면 전체에 걸친 **시각 규칙**만 적습니다.

## 1. 아이덴티티 — 비주얼은 아래로 꺾인다

큰 비주얼은 아래쪽 가운데가 V자로 내려옵니다. 사이트를 알아보게 하는 첫 번째 표식입니다. 기준 시안은 피그마 18155-8483입니다.

```
┌───────────────────────────┐
│                           │
│          비주얼           │
│                           │
└──╲                     ╱──┘   ← 양 끝: 높이 − 꺾임 깊이
     ╲                 ╱
       ╲─────V───────╱          ← 가운데: 비주얼 맨 아래
```

- **쓰는 법**: 비주얼 상자에 `.is-folded` 클래스를 붙입니다(`css/site.css`). 잘린 양쪽에는 그 아래 바탕이 비칩니다.
- **깊이**: `--fold-depth: clamp(40px, 7vw, 136px)`입니다. 1920 폭에서 약 130px로 시안과 같고, 모바일에서는 40px입니다.
- **쓰는 곳**:
  - 메인 KV 사진(`.kv__slides`)
  - 서브 페이지 상단 비주얼: 브랜드 소개 · 캠퍼스 안내 · 오시는 길 · 교육 프로그램(2 · 3단계에서 붙임)
- **쓰지 않는 곳**: 카드, 썸네일, 팝업, 본문 속 작은 사진. 꺾임은 「페이지의 첫 큰 그림」에만 씁니다. 여러 번 쓰면 표식이 흐려집니다.
- **위에 얹는 것**: 글 패널처럼 비주얼 위에 뜨는 요소는 꺾인 부분(아래 `--fold-depth`)을 피해 둡니다. 모바일에서는 패널이 꺾임에 반쯤 걸쳐도 됩니다.

| 요소 | 값 |

| 패널 | 왼쪽 화면 끝에서 뻗어 나온 카드, 사진 위에 뜸 · 바탕 #EEEFEC 92% + 블러 · 모서리 0 / 60 / 160 / 0 · `--shadow-lg` |

피그마 18144-10173을 따릅니다. 오른쪽 위(헤더 아래 24px)에 폭 88의 흰 카드가 있고, 그 아래 따로 떨어진 TOP 카드가 있습니다. 묶음 사이는 짧은 가로선으로 나눕니다(32px, 16px). 모바일은 오른쪽 아래 버튼 둘(관심고객 등록 · TOP)로 둡니다.

## 4. 아이덴티티 — 육각형 호버

선택과 호버는 **좌우 끝이 뾰족한 육각형 띠**로 짚습니다(피그마 18166-8652). 꺾인 비주얼과 같은 「모서리를 접은」 언어입니다.

- **모양**: 글자 높이 22px의 띠, 좌우 끝을 7px씩 뾰족하게 접습니다. CSS `clip-path: polygon(7px 0, calc(100% - 7px) 0, 100% 50%, calc(100% - 7px) 100%, 7px 100%, 0 50%)`, 좌우 안쪽 여백 15px(뾰족한 7 + 8).
- **색**: 바탕 위에 검정 16%를 덮고, 글자는 Bold로 바꿉니다. 굵어져도 옆 항목이 밀리지 않게 굵은 폭을 미리 잡아 둡니다(`data-label`).
- **쓰는 곳**: GNB 2depth(호버 · 키보드 포커스 · 현재 페이지), 메인 비주얼의 관심고객 등록 버튼(높이 48, 좌우 14px 접음, `--primary-normal2` 바탕에 흰 글자). 앞으로 탭 · 필터 같은 선택 표시도 이 모양을 씁니다.
- **쓰지 않는 곳**: 그 밖의 버튼(알약 모양 유지), 카드.

## 5. 색 — Primary 2번째 색

| 토큰 | 값 | 피그마 | 쓰는 곳 |
|---|---|---|---|
| `--primary-normal2` | `#F19A2F` | Semantic/Primary/normal2 (18166-8712) | GNB 2depth 판, 메인 관심고객 등록 버튼, 알림 배지, 센터 바로가기 핀 |

Primary(`--primary-normal`, Stone Gray)가 글자 · 버튼의 기본색이고, normal2는 **브랜드 포인트로 넓게 까는 면**에 씁니다. 그 위 글자는 흰색입니다.

## 6. GNB

피그마 18103-6570. 상단 배너(18126-6525)는 넣었다가 뺐습니다(2026-10-29).

- **GNB**: 위 28 유틸 바와 아래 메뉴 바로 나뉩니다. 로고는 108×40이고, 메뉴는 세방고딕 16 Regular · 검정 78% · 간격 72입니다. 호버 · 현재 메뉴는 Bold로 바뀝니다. 2depth는 메뉴 글자 왼쪽 끝 아래에 `--primary-normal2` 판(r8, p16, 폭 175)으로 열리고, 항목은 흰 글자 16에 육각형 호버입니다.
- **바탕**: GNB는 늘 흰색입니다. 인트로 동안에는 숨겨 두었다가, 인트로가 끝나면 위에서 내려옵니다. 투명 → 호버 흰색(elankorea.com 방식)을 적용해 봤다가 되돌렸습니다(2026-10-29).
